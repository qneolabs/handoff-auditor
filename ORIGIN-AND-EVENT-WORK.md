## Included event implementation

This repository is built from the standalone local prototype and Meta integration artifacts prepared in the November 3 workspace: evidence/review interface, deterministic checks, Meta-only request/validation/diagnostic modules, draft continuation packets, offline replay, synthetic examples and software tests. The source-lineage hashes are recorded in SOURCE-PROVENANCE.json.

`runtime/baseline/` means the independent local prototype used as this event integration's baseline. It is not a copy of Work Core or a pre-event Work Core checkout. The runtime modules and app source come from the inspected local artifact chain; the Git repository itself is new.

The public-sharing derivative redacts plaintext provider request/response and local authorization identifiers, labels the exported packet as a sharing copy, and preserves source text, claims, finding and draft/open state. The runtime keeps only SHA-256 denylist fingerprints for both consumed authorization IDs so neither can be reused. This narrowly scoped privacy correction changes the sharing proposal, authorization validation and portable regression tests; those changes are recorded in SOURCE-PROVENANCE.json. The two original real results and consumed guards remain outside this repository and unchanged. Fixture-test scratch files are excluded.

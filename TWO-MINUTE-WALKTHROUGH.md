# Two-minute hands-on walkthrough

This is an optional quick walkthrough of the local app, separate from the three-minute entry video. Use the [README](README.md) to start the loopback server. No credentials or model call are needed.

1. **0:00–0:20:** Keep Recorded Meta result selected. Read the provenance banner: synthetic evidence, historical request and zero new calls.
2. **0:20–0:55:** Choose Replay saved Meta result. Inspect the open M-01 finding and open E-01 to read the exact source. The source says approval is pending despite the claim of live acceptance.
3. **0:55–1:20:** Preview the packet. It remains DRAFT, reviewer unrecorded and M-01 open. Downloads preserve the labelled sharing copy; tracking identifiers are redacted.
4. **1:20–1:45:** Return to Evidence, select Unsupported readiness + stale decision, and run the simulated audit. These two findings are deterministic checks, separate from the recorded Meta finding. Leave review controls untouched.
5. **1:45–2:00:** Return to Recorded Meta result, replay and preview the draft packet. Finish with the draft/open status visible.

Viewing a source or packet does not resolve its evidence gaps. The recorded response is not live inference or a model benchmark. See [validation](VALIDATION.md) for local software checks and their limits.
